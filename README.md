Der Job Tracker ist ein einfaches, modernes Kanban-Board, mit dem man den Überblick über alle Bewerbungen behält. Bewerbungen lassen sich per Drag & Drop ganz leicht durch verschiedene Phasen wie Wunschliste, Beworben, Interview, Angebot oder Absage verschieben. Über die Suchleiste, Filter und Sortieroptionen findet man schnell die passenden Firmen, Jobtitel oder Orte. Detaillierte Infos wie Gehalt, Links und Notizen lassen sich in einer seitlichen Detailansicht einsehen, und nicht mehr benötigte Bewerbungen können einfach nach unten in den Mülleimer gezogen und gelöscht werden.

Technisch setzt das Projekt auf Next.js mit dem App Router, TypeScript, Tailwind CSS und Lucide Icons für das Styling, dnd-kit für die Board-Interaktionen sowie Prisma ORM mit einer PostgreSQL-Datenbank. Um das Projekt lokal zu starten, klont man das Repository, führt npm install aus, trägt die eigene Datenbank-URL in eine .env-Datei ein und führt npx prisma db push sowie npx prisma db seed aus. Mit npm run dev ist die Anwendung anschließend unter http://localhost:3000 erreichbar.
